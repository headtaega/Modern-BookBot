# BookBot

A program that counts the characters and vowels.
(With the help of Boot.Dev)

## Features

* Reads text files

* Counts characters and vowels

* Modern finish

* Open-Source

## Usage

Run the program with a book file path:

```bash
python3 main.py books/frankenstein.txt
```
## Installation

1. Clone or download the project
2. Make sure Python 3 is installed:
```bash
   python3 --version
```
3. Add book files to the `books/` folder
4. Run the program
